This unofficial extension runs on your own Anthropic API key. The key is stored locally in your browser (chrome.storage.local) and is sent only to api.anthropic.com — never to any other server.

Get a key at console.anthropic.com → API keys. Each analysis costs a fraction of a cent on Claude Haiku. Prefer not to use your own key? Use the hosted website instead — see the project README.
